# Handoff CR: ปรับชื่อและ Workflow เมนูวางบิลเคลม 2 เมนู

## สรุปการเปลี่ยนชื่อเมนู

| เมนูเดิม | เมนูใหม่ | Page / บทบาท |
|---|---|---|
| วางบิลเคลมลูกค้า | ตั้งเบิกกองทุน | รายการตั้งเบิกเคลมลูกค้าและเคลมโรงพยาบาล |
| วางบิลเคลมโรงพยาบาล | ตรวจสอบรพ.วางบิล | ตรวจสอบและอนุมัติรายการวางบิลจากโรงพยาบาล |

ข้อกำหนด:

- เปลี่ยนเฉพาะชื่อที่แสดงใน Sidebar, Breadcrumb และ Page Title
- ไม่สร้างเมนูซ้ำ และไม่เปลี่ยนสิทธิ์ของเมนูอื่น
- คง Route/Function เดิมไว้เป็น Compatibility Alias หากมีการเรียกจากโค้ดเดิม
- ใช้ Mock Session State ใน Prototype เท่านั้น

## เมนู: ตั้งเบิกกองทุน

- Page ID: `billingClaimPage`
- เลือกประเภทเคลม: เคลมลูกค้า / เคลมโรงพยาบาล
- รองรับ Filter PH/PA, สาขา, ผู้ทำรายการ และ Search
- ประเภทเคลมโรงพยาบาลแสดงเฉพาะรายการสถานะ `รอตั้งเบิก`

### ตารางเคลมโรงพยาบาล

- วันที่อนุมัติเคลม
- เลขที่ Case
- ชื่อสถานพยาบาล
- ผู้อนุมัติ
- จำนวนเงินตั้งเบิก
- บริษัทประกัน
- ดำเนินการ

## เมนู: ตรวจสอบรพ.วางบิล

- Page ID: `billingHospitalReviewPage`
- แสดงรายการวางบิลโรงพยาบาลที่รอตรวจสอบ
- เปิดรายละเอียดเคลม เอกสาร ค่าใช้จ่าย และผลพิจารณา
- รองรับการอนุมัติรายการ

### การปรับจากเมนูเดิม

- เพิ่มข้อมูลอุบัติเหตุจราจรแบบ Read-only/Disabled
- เปลี่ยนหัวข้อเป็น `แจ้งผลการพิจารณาโรงพยาบาล`
- เปลี่ยน `รอแก้ไข` เป็น `แจ้งแก้ไข`
- ตัดปุ่ม `ยกเลิก`
- ตัดปุ่ม `บันทึกแบบร่าง`
- ตารางเอกสารตัดคอลัมน์ `ผลการตรวจ` และ `หมายเหตุ`

## Business Rule: อนุมัติรายการวางบิลโรงพยาบาล

เมื่อกด `อนุมัติ` ในหน้า `ตรวจสอบรพ.วางบิล`:

1. เปลี่ยนสถานะจาก `รอตรวจสอบ` เป็น `รอตั้งเบิก`
2. บันทึกวันที่อนุมัติและผู้อนุมัติ
3. นำรายการออกจากหน้าตรวจสอบรายการวางบิล
4. ส่งรายการไปแสดงที่ `ตั้งเบิกกองทุน > เคลมโรงพยาบาล`
5. คงเลขที่ Case, โรงพยาบาล, ผลิตภัณฑ์ และจำนวนเงินเดิม
6. ป้องกันการอนุมัติซ้ำหรือสร้างรายการซ้ำ
7. แสดงข้อความยืนยันและนำผู้ใช้ไปยังหน้าตั้งเบิกกองทุน

## Compatibility Alias

- `showBillingCustomerPage()` → เปิด `ตั้งเบิกกองทุน`
- `showBillingHospitalPage()` → เปิด `ตรวจสอบรพ.วางบิล`

## Acceptance Criteria

- Sidebar แสดงชื่อใหม่ถูกต้อง และไม่มีชื่อเดิมซ้ำ
- Breadcrumb และ Page Title ตรงกับชื่อเมนูใหม่
- อนุมัติแล้วรายการย้ายไป `ตั้งเบิกกองทุน > เคลมโรงพยาบาล`
- รายการไม่ค้างในหน้าตรวจสอบและไม่ถูกสร้างซ้ำ
- ข้อมูล Case, โรงพยาบาล, ผลิตภัณฑ์ และจำนวนเงินยังตรงกับรายการเดิม
- เมนูเคลมลูกค้าและเมนูอื่นไม่ถูกกระทบ
- รองรับ Desktop, Tablet และ Mobile
