# ClaimAgent Hospital OPD

## วิธีเปิดใช้งาน
เปิดไฟล์ `index.html` ด้วยเบราว์เซอร์ได้เลย ไม่ต้องติดตั้งอะไรเพิ่ม (ไม่มี build step)

ต้องคง**โครงสร้างโฟลเดอร์**นี้ไว้เหมือนเดิมเสมอ (ห้ามแยกไฟล์ .js ออกจากโฟลเดอร์ js/ หรือย้าย index.html ไปอยู่คนละที่กับโฟลเดอร์ js/, css/):

```
project/
├── index.html
├── AGENT.md
├── README.md
├── css/
└── js/
    └── menu-billing-hospital-review.js
```

## เพิ่มเมนู/หน้าใหม่
อ่านวิธีละเอียดใน [`AGENT.md`](./AGENT.md) — มีรูปแบบไฟล์, ตัวอย่างโค้ด, และกติกาการตั้งชื่อ

## หมายเหตุ
โปรเจกต์นี้กำลังอยู่ระหว่างทยอยแยกไฟล์จากไฟล์ index.html ก้อนใหญ่ก้อนเดียวในอดีต เมนูส่วนใหญ่ยังอยู่ในไฟล์หลัก มีเพียง "วางบิลเคลม > เคลมโรงพยาบาล > ตรวจสอบรายการวางบิล" ที่แยกไฟล์แล้ว
